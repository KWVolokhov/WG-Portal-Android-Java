
можно ли для работы ИИ ollama использовать GPU нескольких видеокарт и отключить монитор от Компа чтобы не занимал видеопоток?
Да, Ollama поддерживает работу на нескольких видеокартах (Multi-GPU) и может автоматически распределять слои нейросети между ними. Также вы можете отключить монитор от компьютера — для вычислений искусственного интеллекта наличие активного видеовыхода или монитора не требуется.
Ниже подробно описано, как это настроить и какие нюансы нужно учесть.
🛠️ Работа с несколькими видеокартами (Multi-GPU)
Ollama по умолчанию пытается использовать все доступные видеокарты от одного производителя (например, несколько карт NVIDIA).
Автоматическое распределение: Если модель (например, Llama 3) целиком не помещается в память (VRAM) одной видеокарты, Ollama автоматически перенесет оставшиеся слои модели на вторую карту.
Требования к видеокартам: Лучше всего использовать карты одной архитектуры (например, две карты NVIDIA RTX). На картах NVIDIA вычисления будут идти через CUDA. Совмещать карты разных брендов (NVIDIA + AMD) в рамках одного процесса Ollama пока не умеет или это работает нестабильно.
Как управлять видеокартами?
Если вы хотите, чтобы Ollama использовала только конкретные карты, настройте переменную окружения CUDA_VISIBLE_DEVICES перед запуском сервиса:
CUDA_VISIBLE_DEVICES=0,1 — использовать первую и вторую видеокарты.
CUDA_VISIBLE_DEVICES=1 — использовать только вторую видеокарту.
🖥️ Отключение монитора (Headless-режим)
Вы можете полностью отключить монитор от ПК. Видеокарты без проблем продолжат выполнять параллельные вычисления (CUDA / ROCm), так как Ollama работает напрямую с ядрами GPU и видеопамятью, минуя вывод изображения.
Важные нюансы при отключении монитора:
Экономия памяти: Отключение монитора — это отличная идея. Операционная система и графическая оболочка больше не будут занимать драгоценную видеопамять (VRAM) на вывод рабочего стола. Вы освободите от 500 МБ до 2 ГБ VRAM для нужд ИИ.
Эмуляторы монитора (Dummy Plug): В редких случаях на Windows видеокарта может «уснуть» или снизить частоты, если к ней ничего не подключено. Если вы заметите падение производительности после отключения монитора, купите копеечную заглушку HDMI/DisplayPort dummy plug (эмулятор монитора). Компьютер будет думать, что монитор подключен, но реальный экран вам не понадобится. На Linux (Ubuntu/Debian) такой проблемы обычно нет, там все отлично работает в режиме "headless" сервера.
Если вы планируете запускать конкретную тяжелую модель, подскажите модели ваших видеокарт и объем их памяти (VRAM). Я помогу рассчитать, поместится ли модель полностью в память для максимальной скорости работы!

Для реализации такого сценария стандартный консольный интерфейс Ollama не подойдет, так как он умеет только выводить текст в консоль. Чтобы Ollama могла сама перезаписывать файлы в папке проекта в «тихом» режиме (Silent), вам нужен скрипт-автоматизатор (на Python или Bash/PowerShell), который будет отправлять код в Ollama через API, забирать ответ и сохранять его в файлы.
Ниже готовое решение, как это настроить, и готовый скрипт для автоматизации.
🛠️ Как это работает в связке с Git (Ваш пайплайн)
Подготовка: Вы делаете git commit перед запуском, чтобы зафиксировать рабочее состояние.
Запуск: Запускаете скрипт автоматизации, передав ему задачу и путь к файлу/папке.
Silent-режим: Скрипт отправляет код в Ollama, получает обновленный код, молча перезаписывает файлы и завершает работу без лишнего текста.
Этап Tune (Ревью): Вы пишете git diff, видите все изменения, внесенные нейросетью, и сами решаете, что оставить, а что поправить.
📜 Скрипт для автоматизации (Python)
Так как у вас ноутбук с 20 ГБ RAM, скрипт настроен на использование модели qwen2.5:3b или llama3.2:3b (они отлично подходят для кодинга на процессоре и не зависают).
Установите библиотеку для работы с API Ollama:

Создайте файл ai_coder.py в корне вашего проекта и вставьте в него код:
python
import os
import sys
import ollama

# --- НАСТРОЙКИ ---
# Используем легкую модель, подходящую для CPU ноутбука (например, qwen2.5:3b или llama3.2:3b)
MODEL_NAME = "qwen2.5:3b" 

def modify_file_silent(file_path, task_description):
    if not os.path.exists(file_path):
        print(f"Ошибка: Файл {file_path} не найден.")
        return

    # 1. Читаем текущий код файла
    with open(file_path, "r", encoding="utf-8") as f:
        current_code = f.read()

    # 2. Формируем строгий системный промт (Silent-режим)
    system_prompt = (
        "Ты — инструмент автоматической перезаписи кода. "
        "Выполни задачу пользователя. В ответе выдай ТОЛЬКО обновленный код файла целиком. "
        "Не пиши никаких объяснений, приветствий, комментариев или markdown-разметки (без ```python). "
        "Твой ответ должен начинаться сразу с кода и заканчиваться кодом."
    )

    user_prompt = f"ФАЙЛ:\n{file_path}\n\nТЕКУЩИЙ КОД:\n{current_code}\n\nЗАДАЧА:\n{task_description}"

    # 3. Отправляем запрос в локальную Ollama
    try:
        response = ollama.generate(
            model=MODEL_NAME,
            system=system_prompt,
            prompt=user_prompt,
            options={"temperature": 0.2} # Низкая температура для более точного кода
        )
        
        updated_code = response['response'].strip()

        # Очистка от случайных тегов разметки, если модель их добавила
        if updated_code.startswith("```"):
            lines = updated_code.splitlines()
            if lines[0].startswith("```"): lines = lines[1:]
            if lines[-1].startswith("```"): lines = lines[:-1]
            updated_code = "\n".join(lines)

        # 4. Перезаписываем файл (Silent)
        with open(file_path, "w", encoding="utf-8") as f:
            f.write(updated_code)
            
    except Exception as e:
        print(f"Ошибка при запросе к Ollama: {e}")

if __name__ == "__main__":
    if len(sys.argv) < 3:
        print("Использование: python ai_coder.py <путь_к_файлу> '<задача>'")
        sys.exit(1)

    target_file = sys.argv[1]
    task = sys.argv[2]
    
    modify_file_silent(target_file, task)
Используйте код с осторожностью.

Модели семейства Qwen 2.5 (3B или 7B Coder) и Llama 3.2 прекрасно справляются с обоими языками, так как обучены понимать контекст заголовочных файлов .h, исходников .c/.cpp и структуры классов .java.
Давайте адаптируем наш скрипт под эту специфику. Android Native требует строгой точности в JNI-сигнатурах и типах данных (jenv, jobject), поэтому мы усилим системный промт, чтобы модель не ломала структуру кода.
🛠️ Модернизированный скрипт для Java и C (Android)
Сохраните этот скрипт как ai_coder.py. Он умеет автоматически определять расширение файла (.java, .c, .cpp, .h) и жестко требовать от Ollama соблюдения синтаксиса конкретного языка без лишней текстовой "болтовни".
python
import os
import sys
import ollama

# Рекомендуется qwen2.5:3b (быстро на CPU) или qwen2.5-coder:7b (умнее, но медленнее)
MODEL_NAME = "qwen2.5:3b" 

def modify_android_code(file_path, task_description):
    if not os.path.exists(file_path):
        print(f"Ошибка: Файл {file_path} не найден.")
        return

    # Определяем язык для подсказки ИИ
    _, ext = os.path.splitext(file_path.lower())
    lang_context = "Java (Android SDK)"
    if ext in ['.c', '.cpp', '.h']:
        lang_context = "C/C++ (Android NDK, NativeActivity)"

    with open(file_path, "r", encoding="utf-8") as f:
        current_code = f.read()

    # Сверхстрогий промт для Silent-режима под Android разработки
    system_prompt = (
        f"Ты — специализированный инструмент автоматической перезаписи кода для {lang_context}.\n"
        "Выполни задачу пользователя. В ответе выдай ТОЛЬКО обновленный код файла целиком.\n"
        "Запрещено: писать пояснения, вступления, выводы или использовать markdown-разметку (без ```).\n"
        "Ответ должен содержать исключительно валидный исходный код, готовый к компиляции.\n"
        "Сохраняй структуру импортов (Java) или инклудов (C), если задача не требует их изменения."
    )

    user_prompt = f"ПУТЬ К ФАЙЛУ: {file_path}\n\nТЕКУЩИЙ КОД:\n{current_code}\n\nЗАДАЧА:\n{task_description}"

    try:
        response = ollama.generate(
            model=MODEL_NAME,
            system=system_prompt,
            prompt=user_prompt,
            options={"temperature": 0.15} # Низкая температура снижает шанс "галлюцинаций" в JNI/C
        )
        
        updated_code = response['response'].strip()

        # Очистка от случайной markdown-разметки, если модель ее забыла убрать
        if updated_code.startswith("```"):
            lines = updated_code.splitlines()
            if lines[0].startswith("```"): lines = lines[1:]
            if lines[-1].startswith("```"): lines = lines[:-1]
            updated_code = "\n".join(lines).strip()

        with open(file_path, "w", encoding="utf-8") as f:
            f.write(updated_code)
            
    except Exception as e:
        print(f"Ошибка Ollama: {e}")

if __name__ == "__main__":
    if len(sys.argv) < 3:
        print("Использование: python ai_coder.py <путь_к_файлу> '<задача>'")
        sys.exit(1)
    
    modify_android_code(sys.argv[1], sys.argv[2])
